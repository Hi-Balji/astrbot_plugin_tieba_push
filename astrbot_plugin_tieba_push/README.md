## 📖 简介

在每天配置的时间点,自动抓取指定贴吧的**热门图文帖**,推送到白名单群聊:

- 🔥 按回复数选取热门帖(跳过置顶、纯文字帖)
- 🖼️ 图片优先直取**贴吧原图**(免登录,多数图可达 1000px+),取不到自动回退缩略图
- 📦 **每个图文帖一条合并转发**(内容=标题+图片);视频帖单独直发
- 🏷️ 已推送过的帖子自动去重(记录保留30天,不会反复推同一帖)
- ⏰ 每天可配置多个推送时间点
- 👮 管理员可通过指令手动触发

默认贴吧:**搬石 / 核战避难所 / 地狱笑话 / 吊图**(可自行增删),每个吧每次推送 **2** 条。

## 📦 安装

WebUI → 插件管理 → 从插件包安装 → 选择 zip。依赖仅 aiohttp(AstrBot 自带)。

## ⚙️ 配置(WebUI → 插件管理 → 贴吧定时推送)

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `forums` | list | 四个默认吧 | 贴吧列表(填吧名,不是链接) |
| `per_forum` | int | `2` | 每个吧每次推送的帖子数 |
| `min_replies` | int | `50` | 热度门槛:只推回复数≥该值的帖子(免费渠道无点赞数,以回复数近似);过高会导致中小吧无帖可推,0=不过滤 |
| `push_times` | list | `["08:00","20:00"]` | 每日推送时间点,可多个 |
| `group_whitelist` | list | `[]` | 推送群白名单(群号),**为空不推送** |
| `tieba_cookie` | string | 空 | 贴吧 Cookie,**强烈建议配置** |
| `platform` | string | `aiocqhttp` | 平台标识,NapCat/OneBot 保持默认 |
| `max_images_per_post` | int | `9` | 每帖最多图片数 |
| `max_text_length` | int | `500` | 正文截断长度 |
| `timeout` | int | `20` | 请求超时(秒) |

## 🍪 关于 Cookie(重要)

百度对贴吧页面有反爬,不配置 Cookie 时部分网络环境会被 403 拦截。获取方法:

1. 电脑浏览器登录 [tieba.baidu.com](https://tieba.baidu.com);
2. F12 → 网络 → 刷新 → 任选一个请求 → 请求标头 → 复制**整段 Cookie** 填入配置(关键是 `BDUSS` 字段);
3. Cookie 有效期通常以月/年计,过期后重新复制一次即可。

> 未做二维码登录:百度扫码登录协议需要轮询接口且极易失效,维护成本高;Cookie 方式更稳定实用,故未实现。

## 🚀 使用

- **自动推送**:到点后自动抓取并推送到白名单群(静默执行,不会发"开始抓取"之类提示);
- **手动触发**(仅管理员,私聊或群聊均可):
  ```
  /贴吧推送            # 推送所有已配置的贴吧
  /贴吧推送 地狱笑话    # 只推送指定吧
  ```
- **Cookie 检验**(仅管理员):
  ```
  /贴吧cookie测试
  ```
  返回 ✅(有效,附账号名)/ ❌(无效或过期,需重新复制)/ ⚠️(网络或风控原因无法判断)。

## 🖼 图片清晰度说明

- 插件**始终是先把图片下载到本地再发送**(`data/plugin_data/astrbot_plugin_tieba_push/tmp/`),不是发链接;
- 图片下载**优先走 imgsrc 原图直取**(免登录):用完整图片哈希请求原文件,多数图能拿到 1000px+ 的原图;
- 部分图片(已被删除/外部图源等)原图接口只回占位图,此时自动回退到签名缩略图档(250px 宽)——这是免登录渠道对该类图的稳定上限;
- Cookie 与图片清晰度无关(原图直取不需要登录),只影响 www 兜底通道;
- 临时文件在**每次推送开始时**和**插件启动时**自动清空(保留一轮供协议端读取),不会无限膨胀。

## 📐 推送规则

- **每个图文帖 = 一条独立的合并转发消息**(节点内容 = 标题 + 图片,同一条,不含吧名/作者/正文);
- **视频帖不进转发**,单独直发:标题 + 视频 同一条消息;
- 只推首楼带图/带视频的帖子;已推过的自动去重;
- 每条消息间隔 1.5 秒发送,降低风控风险。

### 💾 存储说明

- 图片/视频在发送前临时落盘于 `data/plugin_data/astrbot_plugin_tieba_push/tmp/`;
- **每轮推送开始时与插件启动时自动清空该目录**(保留一轮的量供协议端读取),长期占用上限约为单轮推送的图文体积,不会无限增长;
- `pushed.json` 为去重记录(纯文本,极小)。

## ❓ 常见问题

**Q: 提示"未解析到帖子(可能被反爬)"?**
当前网络被百度拦截,请配置 `tieba_cookie`;若已配置仍失败,可能 Cookie 过期,重新获取一次。

**Q: 某个吧一直推不出新帖?**
该吧热门帖可能都已推送过(去重生效),等新帖出现即可;或增大 `per_forum`。

**Q: 想推到多个群?**
`group_whitelist` 里填多个群号即可,每个群都会收到。
